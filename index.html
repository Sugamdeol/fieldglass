How this app calls Pollinations

Every reading is one POST https://gen.pollinations.ai/v1/chat/completions with the downscaled frame attached, authorised by the visitor's own Pollinations sign-in (OAuth code flow with PKCE, so the token never leaves the browser and there is no key to paste). The model is openai/gpt-5.4-nano, which the model list serves with paid_only: false and image input, so one reading costs a fraction of a Pollen from the visitor's own balance.

POST https://gen.pollinations.ai/v1/chat/completions
Authorization: Bearer [the visitor's Pollinations token]

{
  "model": "openai/gpt-5.4-nano",
  "response_format": { "type": "json_object" },
  "max_tokens": 1200,
  "messages": [
    { "role": "system", "content": "<the field-observer reading rules>" },
    { "role": "user", "content": [
      { "type": "text", "text": "What can be learned from this photograph?" },
      { "type": "image_url", "image_url": { "url": "data:image/jpeg;base64,<the framed photo>" } }
    ] }
  ]
}

Source: app.js (CFG.chatEndpoint, MODEL, the call() function).
